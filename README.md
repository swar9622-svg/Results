# Student Grades Query System

A lightweight, client-side web tool for viewing student grades from an Excel file. Designed for quick and secure access to academic records.

---

## 📖 About

This system allows teachers and administrators to retrieve a student's complete grade summary by entering a 5‑digit ID. It displays:

- Homework and activity scores per lesson.
- Participation records (absences, lateness, violations).
- Test and project results.
- Weighted averages and total score.

All data is read directly from an Excel file (`.xlsx`) without any server or internet connection – everything runs locally in your browser.

---

## 🔒 Privacy & Data

- **No data is sent anywhere** – all processing is done on your device.
- This is a **demonstration project**.
- All student data, including IDs, names, and grades, are **fictional and used for testing purposes only**.
- You can replace the sample file with your own data while keeping the same column structure.

---

## 🛠 Technologies

- HTML5 & CSS3
- JavaScript (vanilla)
- SheetJS (xlsx) for reading Excel files
